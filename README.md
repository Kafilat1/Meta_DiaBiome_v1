# Meta_DiaBiome_v1
A metagenomic data (FastQ) for diabetes microbiome analysis. Tools included: FastQC, MultiQC, Fastp, Bowtie2, Kraken2, Braken, MEGAHIT, Meta_Quast, MetaBAT2, and dRep output for downstream analysis. Note: cite workflow and underlying tools used.
